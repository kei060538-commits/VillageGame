# Web preview

The current playable prototype is exported automatically with Godot 4.7.2 and deployed to GitHub Pages from the active pull request branch.

The preview is now portrait-first and is intended to mirror the iPhone puzzle layout: magic-circle research is the primary play surface, while village state and multi-century history are presented as surrounding meta information.

The final protagonist art is not committed by this document; the build currently uses an intentional character-art slot/fallback while the public asset decision remains separate.
