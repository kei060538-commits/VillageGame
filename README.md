# VillageGame

Portrait-first mobile magic-circle puzzle game about an immortal witch protecting one village across centuries.

The primary play surface is a semantic magic-circle puzzle. Research breakthroughs become village knowledge, years or decades pass, and the village's threats, culture, and generations change around the unaging protagonist.

Primary commercial target: native iOS / App Store. The GitHub Pages Web build remains the rapid mobile playtest channel.

The Web preview bundles Noto Sans JP during CI so Japanese UI rendering does not depend on Safari runtime font downloads or browser storage.

Visual direction: midnight navy, violet, antique gold, and pale magical light, centered on a silver-haired celestial witch.

Current development branch: `feature/mvp-simulation`.
